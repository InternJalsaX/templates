# Saree Storefront Templates

Ten homepage templates for an Indian saree store, hosted with GitHub Pages.

- **Gallery:** https://internjalsax.github.io/templates/
- **Full design spec:** https://internjalsax.github.io/templates/directions.html

Each template is one self-contained `index.html` (HTML + CSS, Google Fonts) that uses the shared photos in `assets/photos`.
Widths under 960 px get the mobile layout, 960–1279 px show the desktop design scaled to fit, and 1280 px and up use the full desktop layout.

The brand name “Taana”, prices, offers and reviews are sample content. Replace the photos with your own photography before using a template for a live store.
